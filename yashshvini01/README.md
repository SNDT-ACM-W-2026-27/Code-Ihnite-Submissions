Retro Arcade

About the Project
Retro Games is a simple website where users can explore and play classic-style browser games. The project focuses on providing a fun and easy-to-use gaming experience through a clean interface.

Features
- A collection of browser-based games.
- Simple and user-friendly interface.
- Interactive gameplay.
- Responsive styling for a better browsing experience.

Technologies Used
- HTML – Structure of the website.
- CSS – Styling and layout.
- JavaScript – Game logic and interactivity.

How to Run
1. Download or clone the project files.
2. Keep the HTML, CSS, and JavaScript files in their required locations.
3. Open the main HTML file in a web browser.
4. Select a game and start playing.

Project Structure
The folder contains the HTML, CSS, and JavaScript files used to build the website.

Purpose
This project was created as a web development project to practise HTML, CSS, and JavaScript and build an interactive gaming website.

The Gothic Calculator is a web-based calculator that combines basic mathematical functionality with a dark, vintage aesthetic.
Designed with deep burgundy tones, gothic typography, and ornate wallpaper, it offers a unique visual experience.
Built using HTML, CSS, and JavaScript, it supports basic arithmetic operations such as addition, subtraction, multiplication, and division. 
This project showcases how beginner-friendly web development concepts can be used to create an interactive, functional, and visually distinctive application.

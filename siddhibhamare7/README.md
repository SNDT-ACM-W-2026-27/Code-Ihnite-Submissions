# Little By Little - Student Journal

## *Small Steps. Real Progress.*

Little By Little is an interactive student progress journal desgined to help students or any individual set small daily goals, 
track their progress, record little wins, and reflect on their journey.

## Features
- Daily goal tracking
- Calendar based journal
- Personal Reflections
- Little win entries
- Monthly progress tracker
- Saves entries in the browser using local storage

## Built With
- HTML
- CSS
- JavaScript

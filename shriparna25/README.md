**चला, Mumbai!**
One Day, By The Bay, Your Way.

A simple working day planner for Mumbai.

--features:
- An info button about the website at the top right corner.
- Choose your pace for the day.
- Choose your vibe for the day.
- Generate a plan unique for you, or click again to shuffle.
- Choose from 3 curated ready-made plans.
- Info about the developer at the bottom.

Run locally
```bash
npm install
npm.cmd run dev
```

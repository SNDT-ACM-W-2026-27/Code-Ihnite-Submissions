# ESCAPE.EXE
escape into the cyberpunky universe !
https://inshop234.github.io/ESCAPE.EXE/

## Features

- Cyberpunk dashboard UI
- Sticky note / scrapboard panel
- Add notes with different accent colors
- Focus timer with start/pause/reset controls
- Word decrypt game with 5-letter code guessing
- Fully client-side, no backend required

## Tech Stack

- HTML
- CSS
- JavaScript
